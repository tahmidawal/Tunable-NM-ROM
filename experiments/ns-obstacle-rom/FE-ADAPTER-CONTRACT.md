This is the prospective A6 implementation candidate for independent review. Earlier adapter execution readiness is superseded. No NGSolve import, mesh, flow case, FE eigenproblem or FE supremizer has been executed by this lane. `FE-A6-SYNTHETIC.json` is only an array/matrix regression; the prior construction and failures are preserved under `legacy/`; it cannot release reference or training gates. The current G1 FOM files are deliberately insufficient for this adapter.

Its full rule already contains physical points, positive weights, returned velocity/gradient/pressure and both mixed coefficient vectors. The producer's gradient convention is component, derivative coordinate.

The reference author explicitly has **not** certified that `.vol` retains the curved geometry. Both sides require a future reload check. The adapter calls `Mesh(mesh.vol)` and never calls `Curve` after loading. A mismatch stops the bridge; no re-meshing, interpolation, re-curving, point nudging or mesh substitution repairs it silently. Only the fixed nine-state 2D training family is implemented; the conditional 3D family needs its own reviewed extension.

## Frozen construction

For physical diameter $D$, dimensionless integration weight is $w/D^2$. Velocity and pressure coefficients are divided by $U$ and $U^2$. The shared Stokes velocity and pressure-per-physical-viscosity coefficients are loaded from one admitted `common_stokes_lift.npz`. Its producer metadata records the base viscosity, mesh/layout, scales and linear-control evidence. The adapter pressure lift coefficient per dimensionless viscosity is $\pi_LD/U$. Training corrections subtract that same lift; separately solved case initialization vectors remain reference diagnostics, not the definition of the common lift. The natural-outlet physical pressure convention stays unchanged.

All velocity correction essential DOFs must be within the fixed roundoff threshold before being set exactly to zero; the removed maximum is recorded. A6 computes the original sampled singular spectrum first and retains its existing rank references and cutoffs. It then uses deterministic pivoted mass-metric Gram–Schmidt with two orthogonalization passes, saving the actual permutation in $C\Pi=QR$, and forms modes as $QU_R$ from the small-factor SVD. It does not divide snapshot combinations by small singular values. Pressure uses centered corrections; the exact normalized constant is protected during both orthogonalization passes before normalizing any new direction. The constant remains a separately solved first pressure mode.

The fixed checks are QR mass backward error divided by the original rank-reference scale, mass/actual sampled Gram spectral error, singular-value agreement on that scale, and per-case registered-prefix residual-norm agreement against the independent sampled-SVD prefix. Each tolerance is $10^{-10}$. Only aggregate weighted Frobenius error is POD-optimal; those aggregate floors are saved as well. The scales are $S_v=\sigma_{v,1}$ and $S_p=\max(1,\sigma_{p,1}^{uncentered})$. Zero velocity has no eligible registered prefix; zero centered pressure keeps only the constant. Failure does not alter a rank cutoff or select passing columns. The actual pressure-mode evaluations define the Gram used for inf-sup, consistently with the pressure coefficients used in divergence coupling.

Full-spectrum cluster, rank-boundary, retained-maximum and registered-prefix cuts follow central A6, including pressure-tail cuts $p_r-1$. Normalize singular values by their leading nonzero value; adjacent gaps use $\max(64\epsilon,10^{-10}\max(s_i,s_{i+1}))$. Numerical pivot ties within $64\epsilon$ times the maximum squared score go to the smallest frozen index. This is amplitude invariant without claiming unique tail directions across all platforms. See `A6-PROPOSAL.md` and the source-bound numerical metadata for the exact policy. No validation data enter construction.

Let $M$ denote dimensionless FE mass and $K$ the dimensionless gradient Gram. The velocity supremizer solves

$$
(M+K)s_j=b_j,\qquad (b_j)_i=\int_{\widehat\Omega}\psi_j\widehat\nabla\cdot v_i\,d\widehat x.
$$

Velocity essential DOFs are removed; outlet DOFs remain free. Matrix assembly supplies explicit per-element-type integration rules matching the exported full rule. Matrix symmetry, solve residuals and agreement between assembled and sampled test Grams are checked. The full-velocity/same-pressure reference inf-sup value is recovered from $B(M+K)^{-1}B^T$ with pressure-L2 whitening for each registered pressure prefix. It is a reference value, not a passed reduced inf-sup gate.

The scalar velocity-order space solves $(M+K)e=\lambda Me$ with the production velocity essential boundary set and free outlet. Retain 48 scalar modes plus one look-ahead, then emit $(\phi_j,0)$ followed by $(0,\phi_j)$. Maps come from actual tagged component coefficient views; local scalar DOF enumeration, free masks, physical component embedding and diagonal/cross metric blocks are verified. Frobenius block discrepancies divide by a nonzero matching diagonal-block norm and must be at most $10^{-12}$. Never assume a contiguous vector split.

Pressure tests still use 32 scalar Neumann candidates plus one look-ahead; the shifted H1 problem avoids factoring singular Neumann stiffness. Sparse shift-invert uses SciPy `eigsh`, seed 27102026, tolerance $10^{-12}$, cap 2000 iterations and SuperLU COLAMD. There is no fallback/enlargement selected from field errors. Scalar eigenpair residuals, canonical numerical ties, matrix hashes and the look-ahead gap are saved. `gap_checked` means only that the returned cut has a gap; scalar eigenvalue count/completeness is explicitly unverified. The explicit component copies resolve the known vector duplication issue. This follows the generalized-eigenproblem contract of [SciPy eigsh](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.eigsh.html); actual pinned FE use remains untested.

The fixed enumeration is all maximum-prefix supremizers then the ordered explicit component copies, and constant then all pressure modes then scalar eigenmodes. Existing full-rule dependency rejection and normalization must produce exactly 64 H1 momentum tests and 16 L2 continuity tests. The final fixed test selection may end within a component pair according to that recorded common order; only the candidate construction promises both copies. The duplicated constant in the scalar enumeration is deliberately rejected as dependent. The actual retained indices, transforms, Grams and candidate hashes are persisted. No label is taken as proof of pressure stability, outlet observability or good Jacobian conditioning.

## Bounded use and export schema

The prospective caps are encoded in `CAPS`: mixed unknowns, elements, volume/boundary rule points, sparse nonzeros, individual arrays/archives, estimated factor storage and process peak RSS. They are hard stops. The factor estimate repeats the FOM's conservative fill model; it is not a memory guarantee. A reviewed cluster launcher must additionally impose a hard memory/time limit and charge all failed setup work. This source provides no launcher and authorizes no job.

Future invocation is `TrainingFEAdapter.open(manifest).build().export(new_directory)`. Before state recovery, analytic controls check $(y,0)$ and $(0,x)$ volume/wrapped-boundary gradients using an auxiliary degree at least the geometry-map degree. Production polynomial orders do not change. Normal checks use analytic box/radial directions and separate $10^{-10}$ normalized closure on the outer rectangle and obstacle. There is no CLI that searches for snapshots automatically. NGSolve is imported only after admission and source/file checks. Scalar coefficient-function evaluation accepts only a finite real scalar or an array/tuple with exactly one element. Larger, empty, complex or nonfinite results are errors; this explicitly handles the pinned-library singleton-tuple behavior. The `.sol` vector must match the archived mixed coefficients, and evaluating those coefficients must reproduce all archived volume and boundary fields/gradients, mapped points/weights/Jacobians and normal labels. Raw-point evaluation rejects a point outside the saved FE geometry; exact/approximate curved-boundary consistency is a separate gate.

The export contains:

| File | Contents and units |
|---|---|
| `coefficients.npz` | FE coefficients for dimensionless lift velocity, pressure lift per dimensionless viscosity, POD velocity, pressure, supremizers and both fixed test banks. |
| `volume.npz` | Primary `points_dimensionless`, physical geometry sidecars `points_physical`/Jacobians, dimensionless weights, each coefficient field's values and dimensionless first derivatives. Velocity arrays have axes point/component/column, gradients point/component/coordinate/column; scalar arrays point/column. Lift fields retain a singleton column. |
| `boundary.npz` | Same field arrays on the separate positive mapped boundary rule, labels and outward-fluid normals. Only obstacle normals are negated for `force_moments`; other labels retain fluid orientation for flux/balance diagnostics. Surface weights divide by $D$. |
| `training.npz` | Declared training-only dimensionless velocity/pressure corrections and velocity gradients, both explicitly named physical/dimensionless coordinate arrays, dimensionless weights, ordered Reynolds numbers. Physical coordinates are retained only for raw FE lookup and the frozen coordinate-network geometry interface. Its neural-training array digest uses the existing training API's exact hash convention. |
| `manifest.json` | Input/source hashes, layout, rank/ordering/test/eigen/supremizer evidence, caps, versions, setup/export timing, peak RSS, units and hashes of all output archives. `physical_admission` remains false. |

For an eligible registered velocity prefix $r$, take the first $r$ POD columns (or later neural columns) and the first $p_r$ supremizers, with $p_r$ the minimum of $r$ and the saved pressure count. The pressure unknowns are the first $p_r$ pressure columns. Weak LS uses the saved fixed 64/16 tests; mixed POD Galerkin tests equal its actual enriched velocity and pressure trial columns. Squeeze singleton lift columns when constructing `WeakRule`. Boundary gradients use `BoundaryFromVolumeCF` while normals remain on the boundary transformation, following the repaired FOM convention. The [NGSolve NumPy bridge](https://docu.ngsolve.org/nightly/how_to/howto_numpy.html) documents coefficient-array views and sparse COO export; saved evidence is always copied before it can alias mutable FE storage.

All exported field values, lifts, weights and derivatives are already dimensionless, as are the primary coordinates. Metadata expressly forbids `physical_to_dimensionless` on those arrays; physical geometry sidecars are separately named and labelled. All setup, FE recovery, eigen/supremizer construction, sample export and tensor assembly costs are offline costs to retain. Same-CPU online timing still requires the frozen output contract. The current fitted quadrature contracts into the same tensor shape: fewer points alone establish no online solve speedup.

## Glossary

FE: finite elements. DOF: one coefficient in an FE space. G1: preliminary controls. G2: admitted reference/data gate. POD: weighted training snapshot basis. H1: value-plus-gradient function norm. L2: value-only function norm. Supremizer: a velocity enrichment exposing a pressure mode through divergence. Inf-sup: a scaled pressure/velocity coupling diagnostic. Eigenmode: a generalized matrix eigenvector interpreted as an FE function. Prefix: the first columns of one fixed ordered space. Round-trip: saving, reloading and comparing the same geometric/field data. Shift-invert: solve-based eigensolver transformation. COLAMD: a fixed sparse-factor ordering algorithm. RSS: measured process memory. Gram matrix: weighted inner products between basis functions. SVD: singular-value matrix factorization. Spectral norm: largest singular value of a matrix. Cancellation: loss of numerical precision when subtracting nearly equal quantities. SHA256: content digest. COO: sparse coordinate-list representation. Physical admission: all required scientific checks on actual flow results, distinct from source or array-algebra checks.
