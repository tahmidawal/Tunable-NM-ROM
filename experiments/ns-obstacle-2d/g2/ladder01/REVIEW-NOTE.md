# Initial spatial-refinement candidate

This unexecuted source candidate measures the DFG and manufactured controls on three predeclared meshes. It cannot admit reference or training data. The successful native01 producer and binary replay remain retained unchanged in artifacts and Git history.

The exact mesh sizes in the frozen configurations are maxh/obstacle_h pairs `(0.08,0.02)`, `(0.04,0.01)` and `(0.02,0.005)`. All physical, FE-order, geometry-order, solver, quadrature and normal settings retain the accepted controls. Every case uses a fresh interpreter and performs its own fresh-process binary replay. The prescribed-FE trace, affine gradient, actual normal coefficients, positive full quadrature and fixed reload tolerance remain enforced.

The only producer implementation change is a resource-only full-rule point ceiling increase from 100000 to 500000. The original cap remains in the executed native01 source. No point is removed and no integration order is reduced. DOF, element, sparse-matrix, archive and memory guards remain unchanged. Downstream ROM fitting caps are separate and unchanged; this job builds no ROM basis. `RESOURCE-PROJECTION.json` derives numerical projections from the saved native result, full-rule array and sparse matrix records.

For each physical control separately, the whole positive fine-mesh rule is used for both successive mesh comparisons. Every physical point must evaluate in all compared meshes. Lookup explicitly uses `tol=1e-12`; the returned volume-triangle element number and reference/barycentric coordinates are saved. All barycentric coordinates must be at least minus 64 machine epsilons, and the unused reference coordinate must be within that roundoff bound. This prevents a tolerant point finder from silently extrapolating outside a curved element. The original physical-coordinate reconstruction check also remains. An invalid lookup or coordinate disagreement stops that comparison with all requested points and failure details retained; there is no clipping, subset comparison, nearest node, pressure shift or coordinate nudge. The small numerical difference between curved approximate domains can therefore produce an honest comparison failure requiring a separately reviewed integration policy, not a silent workaround.

The runner stops on implementation/control failures, preserves progress and uses a fixed internal deadline and per-process timeout within the batch wall limit. Coarse divergence, force and pressure discrepancies are retained as physical observations and do not prevent measuring finer cases. Successful execution means measurements completed; it does not mean all scientific acceptance criteria passed. The unchanged full reference gates additionally require polynomial, tolerance, quadrature, domain and outlet studies plus conditional uncertainty assessment. No reference ranking or training follows from this initial ladder alone.

Source review covers the small producer-cap delta, the existing unexecuted `compare_fields.py`, fixed configurations, bounded runner, summary and dependency provisioning. Pinned dependencies, final A8 helper, and preflight are unchanged. `SOURCE-CANDIDATE.json` binds all runtime inputs, including the installer descriptor mapped to `REPAIR.json`. No staging or numerical submission is authorized by these files.

## Glossary

Spatial refinement means reducing mesh element size. DFG is the cylinder-in-channel benchmark; manufactured means a chosen analytic field with matching forcing and boundary data. Full rule means every positive mapped integration point. Common rule means the same physical points and weights for comparing fields. DOF is a finite-element coefficient. A producer emits reproducible reference-candidate artifacts; admission is the independent scientific decision that all reference requirements pass.
