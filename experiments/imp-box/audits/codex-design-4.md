3. **Arms 4.1–4.6 — CORRECT within their declared finite-search scope.**

6. **Must-fail controls — NEEDS-RESTATEMENT; nonblocking specification corrections.** A3 removes the impossible universal \(10\times\) requirement and separates numerical, Boolean and structural controls. However, scaling the **production** rule weights by 1.5 against an otherwise identical successor gives \(\rho=0.5\); \(1/3\) applies when the denominator’s rule is scaled instead. Real successor discrepancies also mean neither value is exact in general. The fault still comfortably can cross the registered bar; assert the measured margin rather than the stated equality. Separately, forcing \(e=\infty\) **at** \(j=J\) guarantees rejection only if that level is reached. **Concrete fixes:** correct the MF-Q2 arithmetic and drive MF-AD-cap through forced rejections from \(j_0\) to \(J\), or explicitly initialize a valid controller fixture at \(J\). Require evidence that the cap branch executed. These are smoke-test completion issues: the current must-fire requirement prevents silent acceptance if the test never reaches its target.

Fully censored arms therefore bias against firing rather than manufacturing speed evidence. This is consistent with the pilot’s “targets reached by both methods” interpretation; the broader infeasibility decision remains with the coordinator. A3 fixes BANK-STOP: every required non-deferred entry must have defined affordability and an above-threshold floor, while any below-threshold entry establishes NOT FIRED. **Concrete safeguard:** add fixtures covering one above plus one undefined entry → UNRESOLVED, one below plus one undefined → NOT FIRED, and an entirely censored arm → unresolved main SPEED-STOP. Apply deferred-coverage labels directly to stop claims.

Finer-lattice diagnostics appropriately limit broader field-accuracy interpretations. **Concrete safeguard:** call the test result the speed-up of the **validation-selected pair**; it does not establish the strongest competitor on test data.
