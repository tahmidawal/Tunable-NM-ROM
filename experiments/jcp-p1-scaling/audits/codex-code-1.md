**Ranked blockers**

1. **WRONG — the 3D driver fails before setup.**  
   `p1three.py:37` imports `qstudy` before `p1core` establishes the repository dependency paths. In a fresh interpreter, `import p1three` raises `ModuleNotFoundError: No module named 'engines'`. Importing another lane module first can mask this. Both `smkkern3d` and production 3D jobs need a clean-process import fix.

2. **WRONG — A and B measure different scopes.**  
   `p1time.py:186–195`: each timed A flank calls `setting()` and constructs a new schedule, including JAX scalar arrays, **inside** the measured interval. B’s schedule is constructed outside its evolution interval at `:208`, with the actual timed dispatch at `:216`. Doubled-work intervals also use the contaminated helper at `:249–258`. Prebuild schedules and call arguments; time only dispatch through synchronisation for every arm.

3. **WRONG — the smoke does not exercise every required control.**
   - `make_configs.py:31–53,106–118`: neither smoke nor `acc1024` supplies `reproduce`; consequently `p1acc.py:204` never enters the reproduction gate. CPU inspection confirmed **zero generated configs enable it**.
   - `make_configs.py:68`: smoke doubled work substitutes **R128-CN-R** for registered **R128-BE at 256²**.
   - `make_configs.py:114`, `configs/smkacc.json:96`: the smoke vendor bridge uses **dev2**, whereas A1.5 requires dev6.
   - `p1acc.py:362–433`: no zero-update control is implemented.
   - `test_p1.py:143–145`: no real-record case/time/reference-kind swap control is exercised.
   
   The injected BE identity fault should be a separate execution from the required unfaulted BE doubled-work control.

4. **WRONG — validity does not implement A1.4.**  
   `p1common.py:261–268` checks only output coefficients `W` and the reason-3 count. It ignores decoded fields and recorded internal states. A CPU counterexample with finite `W`, all-NaN fields/states, and zero reason-3 exits returns **True**. Budget exits are correctly allowed, but finite coefficients alone do not establish finite outputs or every step.  
   The analogous 3D check at `p1three.py:225–228` also checks only subsampled coefficients and reasons.

5. **WRONG — reservations are not enforceable across submission failures or concurrency.**  
   `cluster/submit.sh:19–26` checks the ledger, submits, then records the reservation. A crash/timeout after successful submission leaves an unreserved job; concurrent submissions can both pass the same budget and queue checks. `ledger.py:31–47` provides neither locking nor an atomic check-and-reserve operation.  
   `cluster/stage.py:38,70,108` accepts arbitrary hours without checking a certified projection; `RESERVATION.json` is excluded from the staging checksum at `:111`, and submission does not compare it against the actual sbatch limit. Requeues and time-limit increases also lack the A2.6 accounting/enforcement path.

6. **WRONG — mandatory qualification and control decisions are unfinished.**  
   `p1acc.py:160–195` and `p1time.py:140–167` collect useful ingredients but do not produce configuration-level Q1/Q2 decisions, including pooled stationarity, excluded-trivial counts, and “unverified” edge cases. The referenced `p1score.py` and `analyze.py` are absent. Thus A1.3 independent agreement checks, A4.1 subject-wide identity blocking, and the injected-fault outcome demonstration are not executable end to end. Finish that path before treating smoke controls as passed.

7. **WRONG — statistics can declare a registered three-mesh pass with a missing mesh.**  
   `p1stats.py:170` permits two meshes; `:202–203` can return `pass`. `h_acc_n` similarly accepts only P256 at `:105–121`. CPU counterexamples returned **pass** for both. DESIGN requires “registered three-mesh verdict not reached.” Explicitly separate descriptive two-mesh statistics from registered verdicts.

8. **WRONG — retries discard measurement evidence.**  
   `p1kern.py:102–117` and `p1three.py:161–174` retain only the last attempt’s kernel rows. Failed-drift attempts’ 30-call arrays disappear. `p1time.py:227–230` retains only the final attempt’s times plus earlier drift ratios. Persist every attempt, including rejected ones; preserve exclusion decisions separately.
