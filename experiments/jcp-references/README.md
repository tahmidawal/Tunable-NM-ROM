# JCP lane: jcp-references (E0)

Order-verified second-order references for Burgers 2D/3D, Richardson uncertainty, pseudo-spectral cross-check, sealed
and OOD cohorts (generated and QC'd only), loader, old-vs-new comparison. Plan: `reports/2026-10-06-jcp-offmesh-paper-plan.md`
on main (E0 row, K0).

- **Report:** `report.md` (generated by `make_report.py`); plots in `plots/`; pre-registration and amendments A1–A12 in
  `DESIGN.md`; every Codex audit in `audits/`.
- **Loader for other lanes:** `refstore.py` (`load`, `score`, `resolved`, `reference_status`, `restrict`). Local store
  `store/` (git-ignored npz, tracked by `store/MANIFEST.sha256`; `store/STATUS.json` carries dimension status and
  cross-check verdicts). Cluster copy: `JCPREF_STORE=/cluster/tufts/paralab/tawal01/jcp-ref/store`.
- **Sealed/OOD cohorts:** AES-encrypted on the cluster only (`/cluster/tufts/paralab/tawal01/jcp-ref/sealed/`), seeds
  committed as hashes (`checks/sealed_seeds.json`); not readable through the loader; opening is the coordinator's act
  (DESIGN A3.8). Sealing is cooperative and unenforced on the shared account.
- Pipeline: `refjob.py` (cluster job: gates / calib / fd / ps), `collect.py` (pull → store, verdicts, summary),
  `audit_ref.py` (G5), `test_refstore.py` (G6/G7), `cluster/` (stage, submit, fill, harvest, pull, publish).
- Branch `exp/2026-10-06-jcp-references`, mirrored to `origin/codeonly/exp/2026-10-06-jcp-references` by
  `sync_github.sh` after every commit.
