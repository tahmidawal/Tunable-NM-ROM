# Burgers 3D tensor cell — notes, retractions, generated tables

Chronology of the cell defined by `B3D-DESIGN.md` (r3 + r4 amendments). Every table in this file
is generated by `runs/b3dtensor/gen_tables.py` from the run JSONs; the prose records what was
run, what was wrong, and what changed. Numbered items are retractions or amendments that changed a
threshold, a control, or a rule after it had been written down.

## 2026-09-03 — design r1 → r3, phase 0 locally

- r1 audited by Codex `gpt-5.6-sol` (33 items, `B3D-DESIGN-AUDIT-r1-codex-gpt56sol.md`): mathematics
  sound; gates, family, FOM baseline and decision table not. r2 folded every item; audited again
  (17 items, `-r2-`): the undamped Picard arm was not a contraction (gain ≈ 1.2 at $A = 2$,
  $\nu = 0.01$), the F8 control was inert, the F5 central-difference control was not guaranteed to
  fire, the C2 bootstrap was tautological, the named 2D trainer could not train the 3D decoder. r3
  folded those; audited a third time (20 items, `-r3-`), folded as the r4 amendments in the design.
- Code: `b3d_common.py` (self-contained), `b3d_tensor_common.py`, `b3d_fom_gates.py`,
  `sep_b3d_tensor.py`, `sep_b3d_kernels.py`, cluster scripts, `runs/b3dtensor/gen_tables.py`.

**Smoke runs that shaped the controls (local GB10, `jaxrun`, N = 17 and 33):**

1. **Retraction (control).** The F5 control planned in r1/r2 was a central-difference advection
   rollout at cell Péclet ≈ 6. Measured at $N = 17$ and $33$, $\nu \in \{0.01, 0.03\}$: central
   differences with backward Euler stayed non-negative (min $u$ +3e-8 to +8e-7). The control could
   not fire and was withdrawn. A downwind (inverted switch) rollout goes negative by four orders at
   $\nu = 0.01$ but its Newton does not converge (worst residual 1e5 to 1e7), so it is a divergent run,
   not a solver control (r3 audit item 39/55). r4: the asserted control is a deterministic output
   mutation (one node of the accepted state $k = 25$ set to $-2\times10^{-3}$, bar $< -10^{-3}$); the
   downwind run is recorded as a diagnostic with its finiteness and residual. A first version of the
   mutation used $-10^{-3}$ against a strict $< -10^{-3}$ bar and did not fire (caught in the run,
   fixed before any cluster job).
2. **Retraction (control).** The F3 control was two Newton iterations; with the exact Helmholtz
   preconditioner two iterations converge to 2.9e-10 (< 1e-8), so it could not fire. Now one
   iteration (fires at 4.9e-5 at $N = 33$).
3. **Retraction (control).** The r2 F8 control scaled the $z$-Laplacian by 1.01; on the plateau plane
   the $z$ terms vanish identically, so it was inert (0.0). r3 scaled the $x$-advection by 1.01, which
   gave 1.9e-5 under the backward-error normalisation, below the 1e-4 bar. r4: the $x$-advection
   coefficient is doubled (fires at 1.9e-3).
4. **Amendment.** F7's band was to be set by F11's observed order (self-calibrated, audit item 53);
   frozen at $[0.7, 1.3]$ instead. Measured: MMS order 0.85 (with the continuum forcing) and nested-grid
   order 0.83 at $N = 33/65/129$; the F11 forcing now uses the discrete backward-Euler time quotient.
5. **Amendment.** The Fourier matrix $B$ was inside the optimiser tree and therefore trained
   (audit item 62), contrary to "fixed"; its gradient is now zeroed and invariance asserted. (The 2D
   `sep_common.train_autodecoder` has the same property; not changed there.)
6. **Amendment.** The D3 control replaced a row of $A$ by another row, which does not force rank
   loss with $M = 2R$ (it gave 1.8e-3 vs 2.6e-3 in the N = 17 smoke); now a column is duplicated
   (1.3e-18).
7. **Amendment.** The L control dropped the diffusion term and gave 3.9e-4 (below 1e-3); now the
   diffusion sign is flipped in the assembled reference (6.8e-4 at N = 17, bar 1e-5).
8. **Amendment.** The STEP/ROLL gates of the 2D driver (bit-identity against `sep_solvers`) cannot
   be reused: `sep_solvers.make_step_lspg_var` imports `blat_common`, which imports the 2D FiLM
   stack. Replaced by an independently written eager LM (normalised latent and decoded-field
   discrepancies, N = 17: 2.8e-17 and 2.5e-15).
9. **Amendment.** $M$ is extended to the end of its degenerate eigenshell (N = 17, request 64 →
   66).
10. **Observation (not a retraction).** In the N = 17 smoke the `defect` fixed-work rung with exactly
    one accepted correction diverged (error 2.9e3) while zero and two corrections did not: the cubic
    predictor on self-generated history amplifies a weak correction. It is a legitimate rung outcome
    and stays in the ladder as measured.
