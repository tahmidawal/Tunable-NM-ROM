## Glossary

- **arm** — one complete, separately timed way of answering the same query: a reduced-order model at a given setting, or the full-order solver at a given tolerance.
- **pre-optimisation arm** — the solver path the paper's current rows were timed on: LU on the damped normal matrix, no trust-radius clipping, no damping carry-over, no quadratic predictor, unfused residual and Jacobian.
- **optimised path** — the same model with those five changes applied. Each was measured and parity-gated when it was introduced (`experiments/hires-burgers/SPEED-LOG.md`).
- **$q$, $M$** — $q$ is the number of correction directions the reduced model carries; $M$ is the number of fixed weak test functions the residual is projected onto.
- **$m$** — the number of quadrature nodes the empirical rule evaluates the advection at, out of the $(L-1)^2$ interior nodes of the mesh.
- **quadrature rule** (`scaled`, `lat64`, `exact`) — which nodes and weights approximate the advection term. `scaled` transfers a fitted rule from $256^2$ with rescaled weights; `lat64` is a uniform $63\times63$ sub-lattice with equal weights; `exact` uses every interior node (no rule).
- **exact first step** (`_x1`) — the first time step uses the exact residual, the rest the rule.
- **worst / median evolved %** — the relative error at the five evolved output times, measured against the full-order solution on the same mesh at tolerance $10^{-6}$; worst and median over the six development cases.
- **GPU ms / complete ms** — GPU ms times the query with the input already on the GPU and the six outputs left there; complete ms adds the host upload of the input and the host copy of the outputs.
- **the paper rule (FOM by the rule)** — the full-order comparator for a row is the *fastest* tested Newton–BiCGStab setting whose worst error is at least as small as that row's.
- **b-panel grid / lean grid** — the two sets of full-order settings in play. The b-panel grid is the implementation the $256^2$–$1024^2$ rows were selected from; `lean` is the same discretisation and solver without a per-Newton diagnostic, used by the $2048^2$/$4096^2$ rows.
- **parity gate** — an optimised arm that only changes the kernel or the matrix factorisation must reproduce the audited arm's field to $10^{-9}$ *and* take identical iterations. Arms that change the iterates by design (clipping, damping carry-over, predictor, exact first step) are not parity arms; they are judged on their directly measured error.
- **stalled** — a step that exited on its budget, on a tiny step, or on a rejected trial step rather than on the convergence test. Any non-zero count is a warning.
- **held-out $\rho$** — the relative error the quadrature rule makes on states it was not fitted to; a rule is certified when it stays under the bar on every held-out draw. Certificates here are carried from the `burgers-eqcert` lane, not re-derived.
