# Burgers 3D identical-sample reconstruction screen

User-approved reconstruction-only screen, 2026-10-27. Preparation, development and frozen validation have completed and their returned bytes are verified. Independent numerical and artifact acceptance review passed. Dynamics and sealed/OOD cohorts are excluded.

This lane uses the existing frozen W1024 spatial bank and fits coefficients from the identical supplied nodal samples consumed by interpolation and continuous POD. The input sources are restricted E0 fields and independently evolved coarse FOM fields, both at the same physical times. Initial setup and all per-query fitting/decoding costs are accounted separately.

The central design in the coordinator lane governs this document. The local copy includes its pre-reconstruction temporal-ladder amendment. Their archived parameter-table hash is verified, but the original archived snapshot bytes are unavailable. The matched-observation extension and stronger full-native-field extension are distinct controls. The bank additionally used historical validation checkpoint selection and a different training objective; these differences preclude a pure architecture attribution.

All declared accuracy curves remain. Validation cost measurements cover the frozen selected methods, all ordinary methods and unregularized rank curves, with three independent one-field invocations. Other regularized curves are labelled accuracy-only. A continuous GPU query block precedes scoring, with a fresh burn at every case/source block. Costs and accuracies refer to those same invocation outputs.

Preserved artifacts include preparation bases and source/sample hashes, all coarse input rungs, coefficients, geometry transforms, ordinary interpolation arrays, per-repetition timing/output hashes, and representative actual selected validation fields. Large training snapshot matrices are reproducible intermediates and are not pulled locally.

The immutable validation export is [EXPORT.json](results/val01/output/EXPORT.json); the compact [SCREEN_SUMMARY.json](results/SCREEN_SUMMARY.json) is generated by `summarize3d.py` and includes literal-interpolation comparisons, frozen selected controls, timing summaries and the allocation ledger. It performs no validation selection. The raw score, coefficient and timing files remain expanded under each result directory; local Git archives preserve all raw arrays and the large bases. The code-only mirror contains their checksum manifests.

Exact input and source hashes accompany every result. No files outside this worktree are modified except required canonical lab-log entries.

## Glossary
- Interval count: one fewer than total nodes along each axis.
- Bank prefix: a selected number of the existing ordered spatial functions.
- E0: the archived, conditionally qualified second-order numerical reference.
- POD: classical basis obtained from the training snapshots.
- Coarse FOM: numerical PDE solution used only to supply samples to reconstruction.
