## Locked execution

- Architecture: H1, global `48x48` plus central `32x32` hierarchical controls, `k=24`, `q=19`,
  `M=96`, `m=384`; 111,520 hyperdecoder and 2,104 direct-predictor parameters.
- Training: all 51 times from N64 `0:512`, N128 `0:128`, N256 `0:64`; 35,904 autolatents.
  Manifold training is exactly 30,000 AdamW steps at batch 32 / 512 points.  The frozen-
  hyperdecoder direct predictor is exactly 20,000 AdamW steps with the locked train-only feature
  standardization folded into its first affine layer.
- Exposed selection only: all 51 times from N64 `512:576`, N128 `512:544`, N256 `512:528`.
  Three q starts each run the locked 10,000-step/checkpoint protocol; the minimum pooled mean
  snapshot-relative-L2-squared start is selected.  Model validation and confirmation cannot be
  generated by this driver.
- Promotion: learned oracle mean/worst `<=2e-4/7e-4` and direct mean/worst
  `<=3e-4/1e-3` with direct/oracle mean degradation `<=1.5`, separately at every N and pooled.
  A failed oracle licenses same-H1 k32 only when every row is finite/exact-boundary and within
  the exact `4e-4/1.4e-3` near-miss bracket; otherwise it hard-stops.

## Measured smoke and cluster request

The excluded one-update synthetic smoke completed in 37 wall seconds on the local GB10.  Its
reported components were 6.552 s manifold, 6.092 s predictor, and 5.481/4.759/4.713 s for the
three selection starts; these are compile-dominated and are not scientific timing or a linear
runtime extrapolation.  It executed the 3,328-output hierarchical hyperdecoder, exact Cox--de
Boor H1 decoder, predictor-standardization fold, three-start selection, companion writes, and
the immutable P4-D license check without touching locked data.

The scientific cell requests one H200, 8 CPUs, 64 GiB, and 12 hours.  Static retained arrays are
under 8 GiB: regenerated truth is approximately 4 GiB, optimizer/autolatent/schedules are below
1 GiB, and full-grid evaluation is batched by eight snapshots.  The 12-hour request conservatively
covers regenerated fixed8 training/selection truth, 80,000 total optimizer steps across manifold,
predictor, and three q starts, all checkpoint full-field scans, and artifact compression.  CPU
BLAS/OpenMP are pinned to one thread; the 8 CPUs primarily support truth generation and host data
sampling, not a claimed parallel fit speedup.

## Artifact path

Staging is exact-commit only through `cluster/make_phase4_train_cell.sh`; it copies the immutable
P4 JSON/NPZ/AUDIT and nested root manifest to `code/deps/p4/`, binds the inherited runtime
dependency hashes to the P4 manifest, and creates a root manifest excluding only itself.  Launch
and pull are `cluster/launch_phase4_train_cell.sh` and `cluster/pull_phase4_train.sh`.  Pull checks
Slurm/GPU/f64/highest health, retained repetition-independent training artifacts, captured-large-
constant/OOM/disk warnings, the exact source/dependency manifest, and the independent negative-
aware audit before deleting only the exact remote cell directory.
