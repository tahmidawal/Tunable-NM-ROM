## Glossary

**Prefix:** private directory containing an installation's normal library and package layout. **RECORD:** the wheel-installed list of files, sizes and hashes. **Native library:** compiled machine-code dependency. **Fixture:** synthetic bytes used to test file-validation logic without loading code. **Fault reporting:** Python traceback output for fatal native errors. **Mapped-point lifetime:** keeping the object that owns a geometry transformation alive while a point uses it.
