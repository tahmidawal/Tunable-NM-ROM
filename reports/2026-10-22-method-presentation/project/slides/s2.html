What equation do we solve each step?

Ask the solution to satisfy the PDE against sine tests

r(c) = D·( A·c − A·c_old + Δt·( N(c) + ν·Λ·A·c ) )
A = Φᵀ G (shapes against M = 4r sine tests, exact)
D = (1 + Δt·ν·Λ)⁻¹, Λ = sine eigenvalues

  • This is one backward-Euler step written in test space; other schemes change only the time weights
  • Linear terms (time derivative, diffusion) are exact: sines are eigenfunctions of the Laplacian
  • Only N(c), the nonlinear advection, needs approximating
  • LSPG: we minimise ‖r(c)‖ because there are more tests (4r) than unknowns (r)
