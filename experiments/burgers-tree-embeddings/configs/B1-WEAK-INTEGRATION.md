# Structured integration with unchanged fine-grid physics

Dense integration is an expensive diagnostic as the internal fine spacing is refined. Prepare a uniform composite weak integration rule on Q intervals per axis, with Q dividing the fine operator's L. Only integration locations change. Every advection value uses the exact sign-upwind neighbor spacing1/L and decoder values at those five fine-grid stencil points. Fine-grid tested mass and discrete sine eigen-diffusion remain unchanged. This is not coarse-grid physics or strong-form residual collocation.

The initial diagnostic uses deterministic uniform composite weights, not NNLS-fitted weights. No residual snapshots select or fit the rule. Any later empirical NNLS rule must fit decoder-output snapshots and be separately qualified. Cold initial-field fitting uses the same integration rule, and its changed initial physical state is included in the comparison. Require integration points at least4M, common tests for both models, exact local supports and the existing overlap-aware metric. Do not claim integration convergence from that point-count heuristic.

Before a real run, a sub-minute fixture compares all five stencil values to the independently assembled dense grid at Q=L and Q=L/2, compares tested advection, and checks identical CN returned coefficients at Q=L. A bounded exact-index mode-search optimization must match the full-grid eigenvalue sort; it changes no selected tests.

After the registered dense CN pilot, compare Q512 at the same L2048/dt0.0025 and same three cases, reserving30 GPU-minutes. If successful, independently refine to Q1024 with another30-minute reservation. Admission requires finite stationary solves, the physical accuracy contract and at most0.1% returned-field change from integration refinement. Preserve every failed rule. These jobs must fit the active finite batch and concurrency cap before submission. Higher L may subsequently reuse an independently qualified integration level, with fresh fine-spacing operators and convergence checks. This is a route to practical fine-grid solves, not a performance claim or permission to skip dense comparison.
