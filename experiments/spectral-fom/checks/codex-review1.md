The negative controls are non-trivial, but exercise the accurate arm on case 0 only. **Fix:** independently audit full-grid norms using streamed fields, validate scalar/per-time consistency, and label existing audits as partial.

2. **Major — `sp_burgers.py:275–286`: transform selection uses an unburned, fixed-order benchmark.** One warm invocation precedes five measurements, without the required GPU burn-in; only their median is retained. Clock ramp or order effects can select the wrong DST implementation, which then determines the entire spectral ladder. The later A–B–A gates cannot validate this selection. **Fix:** burn before measurements, interleave candidates, and retain every timing sample.
