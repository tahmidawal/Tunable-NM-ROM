# w-ladder — reflective 2D wave correction ladder (2026-09-17)

Lane of the ICLR 2027 data campaign. Question, arms, pre-registered criterion and amendments:
[`DESIGN.md`](DESIGN.md). Report and machine-readable rows: `reports/2026-09-17-w-ladder.md`,
`reports/summary.json` (generated by `generate_w_ladder.py`; nothing typed by hand).

| file | role |
|---|---|
| `ladder.py` | the driver: one mesh per job, all arms, decomposition, consistency checks, retained-value gates |
| `config-{64,256,1024}.json` | per-mesh job configuration; `config-smoke.json` is the local G1 smoke |
| `retained-gates.json` (`make_gates.py`) | archived accel12 / accel07 error values the job must reproduce to 1e-9 |
| `design_table.py` | prints DESIGN §10 A1's table from the archived JSONs |
| `cluster/stage.py` / `collect.py` / `preserve_archive.py` | q-ridge-pattern mechanics: byte-checked staging, checksum collection, Git chunking |
| `audit_ladder.py` | independent NumPy/SciPy recomputation of every reported error from saved arrays |
| `generate_w_ladder.py` | report, summary rows and figure from `artifacts/<attempt>/result.json` |
| `checks/` | G0 replay evidence, smoke logs, audit prompt/trace |
| `runs/<attempt>/` | staged submit directory + collected archive (archive extraction is Git-ignored) |
| `artifacts/<attempt>/` | Git-tracked bounded chunks of the verified archive, `result.json`, `audit.json` |

Run order for one mesh:

```bash
PY=/home/tahmid/Dev/.venv/bin/python
$PY experiments/w-ladder/cluster/stage.py wl64a config-64.json            # stage (byte-checked against HEAD)
# scp runs/wl64a to the namespace, sbatch from tufts-login, squeue before and after
$PY experiments/w-ladder/cluster/collect.py wl64a                          # checksum-collect
$PY experiments/w-ladder/audit_ladder.py wl64a                             # independent NumPy audit
$PY experiments/w-ladder/cluster/preserve_archive.py wl64a                 # Git chunks
$PY experiments/w-ladder/cluster/collect.py wl64a --delete                 # exact remote cleanup
$PY experiments/w-ladder/generate_w_ladder.py                              # report + summary.json + figure
```
