# Codex design audit — burgers-eqcert (2026-09-21)

Independent read-only audit of `DESIGN.md` (pre-addendum), the protocol, and the inherited `hires.py`/`hops.py`/`hfast.py`, run with `codex exec --sandbox read-only` (codex-cli 0.155.1, model gpt-6-astra) with the files inlined on stdin. Dispositions: `DESIGN.md` Addendum A1. Verbatim findings:

1. **Blocker — The certificate omits states where EQ actually runs.** `hfast.evolve` evaluates extrapolated predictor candidates; LM evaluates accepted and rejected trial states. Certifying only saved \(w_k\) cannot support “every state at which the rule is evaluated.” **Fix:** instrument every EQ residual/Jacobian evaluation and certify those states, or explicitly restrict the claim to saved time-step states.

2. **Major — Exact-first-step exclusion is legitimate, conditionally.** Excluding \(k<j\) is honest for a separately labelled hybrid whose first EQ call occurs after the exact steps. But predictors use earlier history, and their extrapolated states remain uncertified. “Exact” also means exact residual evaluation, not an exact solution. **Fix:** verify the switching boundary, preserve predictor/damping history, include all subsequent EQ evaluations, and time the entire hybrid—including initialization and exact steps.

3. **Major — Certification data also select the winner.** The fresh population avoids the disclosed exploration, but “cheapest confirmed arm” uses its outcomes to choose a rule. The glossary’s claim that these trajectories never “choose any rule” is therefore false. Dated addenda do not restore independence if new arms reuse opened populations. **Fix:** treat these draws as validation; freeze the winner and test fresh trajectories, or use simultaneous inference across all candidates.

4. **Major — Five groups of eight are weak evidence, not five substantial replications.** Passing every group is simply zero failures among 40 trajectories. For one fixed method under IID sampling, the one-sided 95% upper bound on trajectory failure probability is about **7.2%**. Correlated states and dense/deployed versions do not increase the independent sample count. Selection further weakens the interpretation. **Fix:** state the target failure probability/confidence and size an independent confirmation sample accordingly; label current results empirical coverage.

5. **Major — The negative control does not validate the whole decision process.** `bad0` might genuinely improve at another mesh; its certification would not prove that the metric is nondiscriminating. Conversely, rejecting it tests neither the accuracy nor speed gate. The inherited check requires only failure of the aggregate certificate, which is weaker than the design’s status “fails” meaning zero passing draws. **Fix:** specify the intended control outcome precisely and add frozen, real-data negative tests for certificate, accuracy, convergence, and verdict propagation.

6. **Major — The error bar is underspecified and sampled sparsely.** The design writes \(\max_{k\ge1}\), but `score` checks only five evolved output times, missing intermediate-step excursions. Normalizing by \(\|u_0\|\) can also produce a materially smaller number than current-state relative error. **Fix:** either check every step or name the claim “worst scheduled-output error”; explicitly freeze the denominator and report current-relative error alongside it.

7. **Major — The FOM comparison can still mislead.** The fastest-tested rule is preferable to the historical tight comparator, but eligibility compares cohort maxima: it does not guarantee the FOM is at least as accurate on each case. Requiring FOM convergence while permitting ROM stalled exits also imposes asymmetric eligibility. **Fix:** state whether matching is cohort-level or casewise; report both errors and convergence statuses, plus an accuracy-qualified FOM frontier including finite stalled outputs as labelled diagnostics.

8. **Major — The mandatory refined-reference control is optional in execution.** Running it last under a deadline permits a completed verdict without the protocol-required matched-accuracy coarse-FOM comparison. Two fixed coarse settings also need not achieve matched accuracy. **Fix:** reserve resources for this comparison and make missing reference coverage an incomplete verdict. Apply the mandated H200/240G requirement to the **reference mesh**, including \(4L\ge2048\).

9. **Major — Independent full-grid error auditing is not supported by the saved artifacts.** Restricted fields for most cases cannot reproduce full-grid norms or detect omitted grid-scale errors. Full fields for case 0 do not audit the worst case elsewhere. **Fix:** independently recompute every decision-driving full-grid error before deleting fields, retain the audit outputs, and verify timed-invocation identity.

10. **Major — The inherited driver can finish despite failed gates.** Repetition identity and repetition-count gates are recorded without enforcing success; reference failures can coexist with `complete=True`. No exact-first-step implementation is present yet. **Fix:** make an explicit acceptance predicate covering required arms, populations, controls, parity, repetitions, references, and audits; test that each failed prerequisite blocks an accepted verdict.

11. **Major — Calling the speed stack “not a parity arm” does not discharge the protocol.** Algorithmic changes may legitimately alter trajectories, but fused arithmetic, structured Jacobians, and other implementation optimizations still require the prescribed parity and same-job evidence. **Fix:** separate algorithmic variants from implementation optimizations, pin inherited evidence, and test hybrid switching and optimized kernels against corresponding unoptimized implementations.

12. **Minor — The scope of success needs sharper wording.** The speed/error bar can fail; the exact-residual fallback does not establish an EQ certificate. Moreover, an advection-projection threshold alone supplies no demonstrated rollout-error guarantee, and dev6 remains development evidence. **Fix:** keep EQ coverage, development accuracy, and speed verdicts separate; never promote “exact residual” into “certified EQ” or these results into held-out generalization.
