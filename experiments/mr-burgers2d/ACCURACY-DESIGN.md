# Fixed-bank Burgers accuracy training and stationary solve controls

This predeclared development study tests whether better initial-state representation and stricter weak solves improve the current separable Burgers model. The source and configuration are frozen before submission; there are no accepted measurements yet.

The experiment continues the approved corrected `2026-09-07-mr-burgers2d` worktree from `b0e7aaa`, under the existing `mr_burgers2d_20260907` cluster namespace in its own `accuracy07` directory. It preserves the learned spatial bank, latent dimension $k=16$, bank width $r=512$, two hidden head layers of width 512, backward Euler with $\Delta t=0.005$, $M=64$ weak modes and $m=256$ empirical-quadrature samples. The FOM-exact sign-upwind advection remains inside the weak operator.

The experiment has a two-by-two ROM design: frozen or refined head, each with the accepted stall-based solver or the strict stationarity solver. The strict solver permits 400 initial-fit iterations and 180 iterations per time step. It stops on normalized first-order stationarity at $10^{-6}$ or the existing absolute residual tolerance; small-step, rejected/nonfinite and budget exits remain distinct, and every state receives a separate stationarity audit. Improvement-based stopping is disabled in this arm. The accepted control retains its original 180/30 iteration limits and improvement tests. Both solvers use the original trust radius derived from the unchanged old training codes. Strict stopping is a control, not a claim that each solve must converge within this budget.

Only the head is trained. The canonical 576 initial fields are regenerated from the original training-family seed 0; no development case enters training. Their exact interior-grid metric uses 1024 intervals, addressing the known near-wall difference between training and finer-grid evaluation. Bank QR factorization gives $G/L=QR$. Targets are $y=Q^T u/L$ with squared perpendicular loss $\|u/L\|^2-\|y\|^2$ retained. Full input fields are generated in batches of eight, never all at once. The head is temporarily expressed in the whitened coefficients $Rh(z)$, so coefficient fitting exactly matches the recorded full-field reconstruction objective up to its immutable bank-orthogonal constant. Conversion back to the original head is verified numerically and the coordinate bank is byte-identical.

Each new training code starts from the nearest old candidate in the whitened field metric, then receives up to 200 strict initial-fit iterations. Every failure is retained. Joint head/code refinement takes exactly 30000 Adam updates with cosine learning-rate decay from $10^{-4}$, batch size 256 and gradient clipping at 10. Relative loss divides each example's squared reconstruction error by its own full-field norm. An equally weighted replay loss retains 4096 frozen teacher outputs at their original recorded training codes, also normalized per field. Replay is explicitly a regularizer using decoded training states, not newly generated PDE truth. Initial and replay errors before and after training are archived separately; no development-driven stopping or endpoint choice is allowed.

The old recorded code pool determines the same empirical-quadrature training-state indices and trust radius for both heads. Quadrature weights are refitted separately for each head and mesh from its decoded old training states. The trained model adds all 576 newly optimized initial codes to the unchanged sampled candidate library for field-based cold initialization. This code-library augmentation is part of the training procedure, not an isolated weight-only effect. Gauss fitting still interpolates the supplied dense initial field at the same 48-by-48 physical quadrature nodes. Physical descriptors only generate data offline and never enter the online head, lookup or solver.

Training finishes and its sole terminal checkpoint is hashed before any evaluation. That same checkpoint is frozen at 64, 256 and 1024 intervals. Evaluation includes all four opened development cases from seed 7090702 and two fresh development cases from seed 911702. The final paper cohort remains sealed. The existing three-level spatial/temporal empirical reference protocol is regenerated on the GPU for all six cases, with the finest reference at 4096 intervals and time step 0.0003125. Lower-mesh continuum uncertainty and any failed refinement criteria remain visible.

All ROM arms and FFT-Helmholtz-preconditioned Newton–BiCGStab controls run on one GPU allocation. The two FOM settings are Newton/linear tolerances $10^{-2}/0.5$ and $10^{-6}/10^{-8}$. Each method receives three shuffled timed repetitions per case and mesh after individual GPU burn-in. Costs and full-field errors come from the same invocation. The primary timer is supplied GPU field to six full GPU output fields; host transfer time is measured around the same invocation. All public and diagnostic outputs are blocked inside the GPU timer. Setup, training, compilation and post-solve scoring are outside it. Full fields, every internal latent, residual, iteration count, stop reason and normalized weak gradient are preserved. No timing samples are excluded; report medians and within-case outlier counts.

A sub-minute local GPU smoke verifies the strict solver against an overdetermined linear least-squares problem, training/head-coordinate conversion, and a toy sampled-upwind rollout with independently recomputed gradients. The real allocation has a three-hour ceiling, float64/highest matrix precision and mandatory GPU-backend preflight. Source/config/checkpoint hashes are staged directly to the private paralab directory. Collection retains restorable checkpoint and output archives with checksums; the exact closed remote directory is deleted only after verification. Existing worktrees remain separate.

## Glossary

- **Bank / head / latent:** spatial feature functions / network mapping reduced coordinates to coefficients / the small unknown coordinate vector.
- **Fixed bank / refined head:** identical spatial features across all arms / newly fitted coefficient network at unchanged capacity.
- **Weak residual:** the PDE mismatch averaged against smooth test functions, with preassembled linear terms and sampled upwind advection.
- **Stationarity:** a small objective gradient, normalized as $\|J^T r\|/(\|J\|_F\|r\|)$; it does not certify physical accuracy or global optimality.
- **QR metric / perpendicular loss:** an orthogonal factorization preserving grid-field least squares / the error outside the learned spatial span.
- **Replay / teacher:** a penalty retaining earlier decoded states / the frozen original model providing those targets.
- **Empirical quadrature:** fitted nonnegative weights on selected spatial samples approximating weak nonlinear spatial sums.
- **FOM / ROM:** full-grid PDE solver / reduced model.
- **Fixed-initial error / current-relative error:** field error divided by the initial reference norm / by the reference norm at each output time.
- **Development / final cohort:** cases available for method development / untouched cases reserved for later confirmation.
- **GPU / host timing:** a complete device-resident query / that same query including supplied-field transfers.
- **Empirical reference margin:** observed spatial plus temporal reference differences; an empirical allowance, not a rigorous error bound.
