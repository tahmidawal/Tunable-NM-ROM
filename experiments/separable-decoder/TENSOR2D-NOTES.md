## Definition of the 2D tensor arm

The FOM advection is $N(u) = u\,(u_x + u_y)$ with the sign-upwind stencil on each axis
(`blat_common.upwind_adv_field`: both axes switch on the same centre value, ghost zeros on all
four walls).  On a field that is positive everywhere it is the fixed backward difference on both
axes, so with the frozen interior bank $G \in \mathbb R^{n_i^2\times R}$ and
$DG = D^-_x G + D^-_y G$ (ghost-zero walls, `b2d_tensor_common.backward_diff_bank_2d`):

$$
\Phi^\top\big(u \odot (D^-_x u + D^-_y u)\big) = h^\top T h,\qquad
T_{ijk} = \sum_{x\in\text{interior}} \Phi_{xi}\,G_{xj}\,(DG)_{xk},\qquad
Q = T + T^{(j\leftrightarrow k)},\qquad q(h) = \tfrac12\,h^\top Q h .
$$

ONE tensor covers both axes.  $T$ is built in f64, blocked over $x$ (16 384 rows per block; the
$n_i^2\times R^2$ intermediate is never materialised — at $N{=}1024$ it would be 34 GB); two
chunkings are compared (gate TB).  The residual is the exlin residual of `sep_burgers_exlin.py`
with `Phi_q.T @ Nu` replaced by $q(h)$: $r_w = w\,[A(h(z)-h(z_n)) + \Delta t\,(q(h(z)) + \nu\lambda A h(z))]$,
$A = \Phi^\top G$.  Jacobian by forward-mode AD (`jax.jacfwd`, as in every other arm).  All arms
share the same IC fit (encoder init + Gram-space LM), the same LM step (`make_step_lspg_var`
replica, gate STEP bit-identical), the same stall rule (`STALL=1e-3`), tolerances, trust region,
warm-start extrapolation and full-grid decode.  The oracle (`full`) arm threads the bank and the
modes as explicit jit arguments (no captured constants).

## Glossary

- **full / oracle** — the advection term summed over every interior grid point with the FOM's
  sign-upwind stencil; the best any sampled rule can do with this decoder; $O(N^2)$ per evaluation.
- **ex** — the incumbent exlin residual: exact linear terms, advection sampled at $m=256$ NNLS
  grid nodes fit on advection rows only.
- **ex_learned** — same, on the $m=M=64$ learned continuous node set of the codesign "n" arm
  (frozen decoder, `sep_codesign.py`), where such a set exists.
- **tensor** — the advection term as $\tfrac12 h^\top Q h$ with $Q$ precomputed from the bank.
- **rel-L2 rollout error** — mean over the 51 states of $\|u_{\text{ROM}}-u_{\text{FOM}}\|_2/\|u_{\text{FOM}}\|_2$ on the full grid.
- **IC ms / latent solve ms / decode ms / e2e ms** — the three separately blocked phases of one
  trajectory (initial-condition latent fit; the 50 implicit LM steps in latent space; decoding all
  51 states on the full grid) and one fused jit doing all three; medians over 8 trajectories x 5
  timed repetitions, all repetitions persisted in the JSON.
- **stop reasons** — how each of the 400 time-step solves ended (`stalled` = relative decrease
  below `STALL`; `budget` = 30 LM attempts; `tol` never reached: the absolute tolerance is
  unreachable for a 64-equation / 16-unknown least-squares residual).
- **LM attempts** — every residual evaluation inside the LM loop, accepted or rejected, per
  trajectory; **accepted Jacobians** — the subset that was accepted (plus one per step).
- **tol-Newton ladder** — the standardised classical FOM: backward-Euler, tolerance-terminated
  Newton with exact-Helmholtz-preconditioned BiCGStab, over (newton_tol, lin_tol) pairs; the
  same residual/stencil as the truth generator.
- **matched rung** — the cheapest ladder rung whose error is at most the ROM arm's;
  **closest rung** — the rung whose error is closest (in log) to the ROM's; **tightest** — the most
  accurate rung.  **paired** — AB/BA alternated head-to-head timing of the ROM arm and the matched
  rung (`sep_common.time_pair`).
- **T0 / TB / TA / TQ / L / A / FOMR / STEP / ROLL / R-lite** — gates: tensor==oracle on
  all-positive decoded states; build-order agreement; algebraic identity vs the fixed backward
  stencil on the training codes; tensor vs oracle residual/Jacobian at 32 latent states
  (recorded); exlin linear part == full-grid linear part; exlin advection == incumbent advection;
  full-grid weak residual == $w\,\Phi^\top R_{\text{FOM}}$; aux-threaded LM step == the project's
  step; aux-threaded rollout == `make_rollout_v2`; checkpoint codes reconstruct the regenerated
  picked training states (lineage).
- **undershoot** — decoded field values below zero where the truth is non-negative; the only
  source of tensor-vs-oracle mismatch (the tensor always looks backward, the oracle switches).
- **positivity audit** — min and fraction of negative interior values over every regenerated
  training state and every test state (truth), and over decoded training states and decoded
  rollout states.
