# Approved frozen Poisson projection and initialization speed factorial

The coordinator reviewed the completed training audit and independently reproduced
the all-development minimax endpoint selection. This bounded continuation uses
the original checkpoint and the scheduled `original_relative` checkpoint recorded
with exact content hashes in `config05.json`. It introduces no training and opens
no sealed final sources. The original coverage and per-field relative loss are
fixed properties of the selected endpoint, not further factors in this run.

Every previously declared development source is retained on both query meshes.
The actual retained smooth-test shells and bank rank are recorded at assembly.
The primary panel crosses sine matrix products versus forward DST and gather,
and mean training code versus nearest cached weak prediction. Each choice uses
the same guarded Gauss–Jordan LM kernel validated in the preceding study. Same-grid
DST and coarse DST with charged interpolation complete the paired timing panel.
The machine-readable configuration fixes every case count and repetition budget.

Every recorded call starts with the full host nodal source and ends with the full
host solution and solver/initialization metadata. Input, fused device and output
intervals are synchronized and retained. The fused device interval includes
projection, optional lookup, nonlinear solving, numerical guards/fallback and
decoding. Separating those device operations would change the fused procedure;
no component microbenchmark is substituted for its measured total. Cache/operator
setup, compilation and warm-up costs are separate offline records. GPU burn-in
precedes each measured call, including the single-call stationary panel.

The cache contains $B h(z_i)$ for training codes only. Nearest-code lookup minimizes
$\|B h(z_i)-f_m\|_2$. It never reads a reference answer or a Gaussian descriptor.
Both projectors retain selected indices, closest distances and runner-up gaps;
relative squared-distance gaps below the recorded numerical threshold are marked
as near ties. The deterministic exact-tie rule chooses the lowest index.

Parity compares actual recorded projection pairs with the **same initialization
choice**. Coefficient, field, latent and initial-scaled residual-norm tolerances
are fixed in the configuration. Changed counters and stop reasons are reported;
bitwise equality is not required. A different selected nearest index fails that
projection equality gate and remains visible with its gap. Mean-code and nearest
starts may reach different local minima and are compared through error, objective,
gradient and failure records, not an equality gate.

The existing stop threshold remains $\tau\|r(z_0)\|_2$ for each call's own start.
A closer start can tighten the absolute threshold and force a stationary exit.
Initial/final residuals, absolute thresholds and reasons are preserved. Cost
changes describe the complete initialization plus existing stopping procedure;
no target is silently re-anchored. Separate fully recorded $\tau=0$ calls cover
every model/variant/case/mesh combination and do not enter speed selection.

Physical discrepancy uses common observation nodes and the finest independently
refined reference norm. Full-mesh discrepancy from same-grid discrete DST remains
separate. The empirical reference adjustment $(e+\delta)/(1-\delta)$ and the
reference allowance are required for development qualification, without claiming
a rigorous continuum bound. Latencies are medians of case-median repetitions;
paired ratios are medians of ratios of case medians. Failures remain in all error
tables. No further GPU study is authorized in this round after this closure.

## Plain-language glossary

- **Projection / DST / gather:** smooth source coefficients / sine transform /
  extraction of the retained coefficients.
- **Code / cache / nearest / near tie:** compact neural coordinate / saved
  training-only predictions / closest predicted weak right-hand side / nearly
  equal first and second lookup distances.
- **LM / GJ / guarded / fused:** damped nonlinear least squares / Gauss–Jordan
  linear solve / residual-checked with fallback / one device procedure.
- **Tau / stationary / parity:** initial-residual reduction target / small
  normalized objective gradient / numerical agreement under declared tolerances.
- **Physical / same-grid / empirical adjustment:** common-observation refined
  discrepancy / discrepancy on the complete requested mesh / observed refinement
  allowance rather than a proven continuum error bound.
- **Endpoint / minimax / factorial:** fixed final training weights / smallest
  worst error across all declared sources / independently crossed choices.
