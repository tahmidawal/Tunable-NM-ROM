# Frozen operator evaluation

This evaluates the available scaling-lane checkpoints on the registered Burgers test cohort. The user explicitly selected the original operator precision for this evaluation on November 15, 2026. Network inference uses float32, including complex64 for Fourier weights, with TF32 disabled. The initial condition, reference solve, returned fields and scoring use float64. Raw latency repetitions are stored by case. The last timed invocation for each case supplies its scored output.

The freeze includes every available final best checkpoint and each retained intermediate budget snapshot. The historical training process stopped by cancellation in some runs before writing its usual final result. Their surviving best checkpoints remain eligible under the same validation criterion. The accounting records and the committed selection manifest identify interruptions, last recorded steps, hashes, and validation scores. A model and data size with no trained checkpoint cannot be scored. A budget snapshot exists only if the training run reached its configured snapshot step. Historical ROM timings were taken in other jobs and must not be used to compute speed ratios.

Validation alone ranks final candidates by the mean of each validation case's worst relative error over the saved times. An intermediate checkpoint can reach the target but cannot be selected as the family headline. The median-error threshold is the preregistered 0.0264 percent. The reference source, case hash, mesh, batch size, warmed timing protocol and model architecture follow the original protocol. One A100 80GB allocation generates the reference from its registered seed and evaluates each frozen checkpoint at the registered precision once. Duplicate prefix and capped-final weights are evaluated as specified by the manifest. A failed inference is retained in its own record. There is no retuning against the test cohort.
