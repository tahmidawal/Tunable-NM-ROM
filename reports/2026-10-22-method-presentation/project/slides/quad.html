Why replace the mesh lattice with off-mesh quadrature?

Off-mesh rules make the error the same on every mesh

  • Off-mesh rules (Gauss, Fibonacci): worst error changes by a factor 1.0001–1.0060 across 256², 1024², 4096²
  • The old mesh lattice: 1.31–2.19 across the same meshes
  • Off-mesh evaluates the nonlinear term on the continuum, so it inherits no grid error

Off-mesh quadrature study 2D (2026-10-01), dev+val, 38 cases · 4

The old method sampled the nonlinear term at mesh nodes, so it carried the mesh's upwind error and changed with the mesh. Off-mesh quadrature evaluates the network and its exact derivative at fixed points in the continuous domain, so the reduced model is literally the same object on every mesh.
