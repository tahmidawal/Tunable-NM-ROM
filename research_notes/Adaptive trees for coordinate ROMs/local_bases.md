## Part 2 of 3: implementable design and caveats

All recommendations/inferences unless explicitly repo/literature.

Scalar field: $u_{\mathcal A,r}(x)=u_{\rm bc}(x)+B_0(x)c_0+\sum_{K\in\mathcal A}\chi_K(x)\widehat B_{\theta,\tau_K}(T_K^{-1}x)_{1:r_K}c_K$, with $T_K(\xi)=x_K+H_K\xi$. $\tau_K$ may identify interior/boundary, material, or scale archetypes. Train local corrections against detail LEFT AFTER coarse approximation. Do not repeatedly relearn full field in each patch. Use fixed-old-window ADDITIVE details. Correction windows need not form a newly normalized partition of unity over current active set.

THREE DIFFERENT KNOBS: (i) increase local rank $r_K$ with old window, mapping and ordered columns fixed => rank nesting; (ii) spatial trial refinement adds child spaces => nesting only if OLD COLUMNS REMAIN; (iii) quadrature refinement integrates SAME space better, does not improve best-approximation floor. A physical tree split does not establish child learned spaces can represent parent restrictions.

EXACT WINDOW-RENORMALIZATION COUNTEREXAMPLE: existing $\chi_i=w_i/S$, $S=\sum_{\rm old}w_j$. Add child bump $w_c$ and renormalize to $\chi'_i=w_i/(S+w_c)$. Keeping old coefficients and setting new child coefficient zero yields $u'_{\rm detail}=[S/(S+w_c)]u_{\rm detail}$, NOT old field where $w_c\ne0$. With one old window =1, represented detail shrinks by $1/(1+w_c)$. Thus retain fixed old windows/add details, OR transform/project coefficients and verify field AND all history transfer. Global $1/L$ averaging factors changed when adding a level can similarly alter old field.

INTERFACES/DERIVATIVES: globally coupled weak solve with smooth overlapping support and physical boundary compatibility. $\nabla_x[\chi_K(x)\widehat b(T_K^{-1}x)]=(\nabla\chi_K)\widehat b+\chi_KH_K^{-T}\nabla_\xi\widehat b$. Ignoring window derivative changes discretization. Abrupt disjoint leaf indicators need deliberate DG/interface-flux scheme; cannot reuse conforming weak form. Artificial zero traces on every nonoverlapping leaf force global coarse field to carry all interface values. Overlap helps traces but does not make solves independent. Narrow patch gradients scale inversely with physical size, so L2 accuracy alone insufficient; inspect energy/derivative error and conditioning.

ORDERING: existing dense global QR/SVD mixes all local columns and destroys compact support. First version: order/whiten ONLY columns with same support; train residual targets; use support-preserving column selection for dependencies; monitor singular values of assembled weighted trial matrix and tested Jacobian; assess block/coarse preconditioning. Training residual targets does not guarantee orthogonality. Subtracting GLOBAL coarse projection from each local feature generally destroys compact support. Local moments/local interpolant subtraction are possible designs, not proven cure here. SGFEM is warning and inspiration, not inherited guarantee.

SHARING: shared bank reduces stored NN parameters, permits batching, but still has independent per-patch coefficients. Per-patch banks fit heterogeneity at storage/training/coverage cost. Middle ground: interior/boundary/corner/material-interface and scale/regime archetypes. Reference-coordinate normalization does NOT prove physical similarity; local diffusion/advection balance changes with h, as do front direction/amplitude/BC/coefficient patterns. Test shared-reference compression versus per-patch compression before neural training.

NS: propose $u=u_0+\sum_K\nabla_x\times[\chi_K(x)\widehat A_K(T_K^{-1}x)a_K]$. Identity $\nabla\times(\chi A)=\chi\nabla\times A+\nabla\chi\times A$ is essential; directly windowed divergence-free velocity instead has $\nabla\cdot(\chi u)=\nabla\chi\cdot u$ generally nonzero. Smooth potential construction preserves CONTINUOUS incompressibility, not automatic no-slip/discrete-FOM/topological flux conditions. Retain suitable global mean/harmonic modes; periodic curl alone cannot provide arbitrary nonzero mean. Physical autodiff avoids forgetting scaling factors.

PRIORITIZED PROPOSED DIAGNOSTIC (NO RUNS PERFORMED):

A. Using saved train/development snapshots and bank evaluations, compute physical-weighted best current-bank projection. Map residual energy and, if reliable derivatives exist, gradient/energy error. Separate from rollout error. If projection already safely below target while time or solver certification dominates, stop representation campaign for that target. Latest Burgers failure makes this gate essential.

B. Identical physical rule/weights, compare curves: (1) weighted GLOBAL POD fields, (2) current bank prefixes, (3) coarse bank + FIXED assembled smooth-windowed LOCAL RESIDUAL POD spaces, (4) coarse + STATE-DEPENDENT selected local patches from larger dictionary, (5) simple shifted/registered residual POD for moving structures. Report total dimension, active dimension, stored dictionary size, evaluation/assembly work SEPARATELY. Fixed global weighted POD is training mean-square optimum; don't claim local beats that mathematical optimum at same total rank.

C. Arm 4 full-target-snapshot patch selection is an ORACLE PROJECTION DIAGNOSTIC only. It estimates headroom available to perfect selection within tested dictionary. Not deployable online algorithm, not measured speed, not generalization. Build bases/tune on training+development only; later online selector must use available information (validated weak local probes), never future trajectory or sealed cases. A negative oracle result strongly discourages that partition/dictionary. Positive result only warrants selector/assembly/dynamics work.

D. Test sharing before neural training: pull train residual patches to reference coordinates using correct weights/overlap/BC. Compare pooled reference-patch POD, per-patch POD, small archetype library. Do held-out LOCATION and held-out SCALE reconstruction. If pooled ranks much worse, single shared NN bank premise unsupported. If per-patch compression itself weak, weight sharing unlikely rescue without different nonlinear representation. Crucial: assemble ACTUAL windowed basis and globally reproject; sum of independent local POD truncation errors isn't actual assembled error.

E. At candidate patch, compare marginal GLOBAL projection improvement from extra local-rank block, child detail spaces, and extra coarse/global mode, normalized against added unknowns and reasonable eval/assembly work. Fast local spectrum => try rank enrichment; splitting only when it demonstrably simplifies approximation. Large residual alone isn't evidence mesh refinement is correct response.

F. Only then correctness-first coercive diffusion pilot with localized heterogeneity: incumbent bank; same bank/tree quadrature; coarse+local POD; coarse+local NN if justified; trusted adaptive FOM, including certified warm-start arm. Full solver residual/error control assesses initial guess. Count all complete-solve cost incl reconstruction, mapping and setup. Failure doesn't justify immediate 3D transient escalation.

MOVING FEATURE INFERENCES: stationary dictionary must cover many possible positions; active patches may be few but detection/activation/transfers/storage remain. If feature alignment collapses spectrum, registration attacks cause more directly than progressively smaller fixed patches. Splitting/merging/deformation/multiple features or stationary heterogeneity may favor local corrections. Possible later hybrid: coarse registered/co-moving field + stationary details near walls/material interfaces, with transformed derivatives/time terms; not small plug-in change.

DECISION: unknown is whether THIS bank's residuals are locally compressible AND predictably localizable with economically small active budget. Recommendation is saved-data oracle + shared-versus-per-patch diagnostic first. No source proves its success, no speed estimate offered. Existing continuous/local POD is mandatory control and can do as well or better. Novelty needs narrowly demonstrated contribution beyond localized ROM/GFEM, multilevel FBPINN, frozen-feature ELM-FBPINN, and tree ROM refinement.
