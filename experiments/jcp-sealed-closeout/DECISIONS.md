# Prospective Burgers quadrature confirmation

The primary question is whether the previously selected Fibonacci and CBC lattice rules and Gauss rules still reach the registered trajectory-error plateau on both originally sealed in-family cohorts. Historical ladder and full-solver settings, algorithms and model weights are unchanged. The one prospective claim here is conditional on the original E0 uncertainty procedure. No further use of these cohorts will be called prospective.

## Population and reference

All 128 2D and 64 3D original physical cases enter. Score both the central Crank–Nicolson space-time reference (primary ST) and backward Euler space-only reference (secondary S). Keep all original case-kind status flags. Accept reference ranking only when E0 accepts that case-kind, dimension status is validated, and the errors are separated by more than twice that case's estimated uncertainty. Report every count, all-case descriptive statistics separately and conditional uncertainty. The original 2D calibration provides two development calibration cases, all base grid levels and the measured residual-floor factor. Preserve its outcomes instead of changing that rule. No new reference generation, replacement of failed cases, reopening for tuning, or OOD case access.

Custody is the already documented cooperative shared-account model. There is no proof of adversarial blinding. The original seed file bundled in-family and OOD seeds; the publisher reads it in private memory during the one authorized transaction and persists only the in-family seeds. It never decrypts OOD fields or metadata. No per-case sealed contents, seed values or original keys are to be committed to public Git. The original cohort had predefined checks and the limited aggregate outcomes of those checks were already public.

## Frozen comparisons

The complete eight historical final mesh panels are defined in configs, including their historical solver, tolerances, derivative convention, iteration limits, rule points, rule weights, time stepping, output lattice, full-solver ladders and raw timing-repetition policy. Each grid contains all historical quadrature ladder rungs, both reference anchors and negative controls. Spacing comprises 256, 512, 1024, 2048, 4096 intervals in 2D and 64, 128, 256 in 3D. No arm or threshold is selected using outcomes of the new cases.

The primary 2D subjects are fib987 and gauss45. The 3D subjects are lat4096 and gl20. The previously selected lattices supply the predeclared extra timing panels on every mesh. For each primary subject report the eligible median and worst errors over cases and the full downstream larger-rung suffix under the upstream anchor, valid-solver, uncertainty and tail-demonstration rules. A chosen size transfers if its own rung and every higher tested rung of its family passes the registered conservative 5 percent margin, the independent anchor audit passes and a tail is demonstrated. A lower newly eligible minimum still supports sufficiency; any new minimum is descriptive and will not be deployed from this cohort. Report fail/unresolved/ineligible without resampling or tuning. Report original solver status, unrankable counts, every full solver's errors and the median plus worst at every model grid. If the primary fields cannot be scored the corresponding claim remains unverified. Retain every measured failure.

For the two preselected native POD controls, use the continuous-source 256 ECSW r256 kappa8 CN-R at native 256-squared, and POD512 unsampled CN with 25 steps at native 64-cubed. Their finest-grid scoring lattices match E0 exactly. Charge the full returned-field cost. Compare errors, terminations and counts with the neural bank and spectral/FOM baselines. Separate allocations forbid a POD/bank speed ratio. No claims about POD transfer to additional meshes. The full-solver alternatives in the large bank panels are each timed together with the bank in that same job. Burn in before timed blocks; use stored repeats, synchronized output-vs-scored checks, paired same-allocation scope and original timing drift guards. Stale cross-job times are never a comparator.

A shared method changes bank width, quadrature accuracy, solver tolerances or convergence rules only on a new independent population. A failed infrastructure run may restart the same immutable configuration; accounting includes failures. If data are missing or a completion guard fails, report the missing or failed panel and withhold its conclusion. Never silently substitute another case, model, solver or timing.

## Computation, admission and prospective decisions

Regenerate each physical input from the original hidden in-family seed, then use its authenticated original row for both bank and POD evaluation. S/ST descriptors and cohort fingerprints must agree exactly within each generation job. In 2D the four uniform draws must agree bitwise and the viscosity to relative tolerance $10^{-14}$. If the original 2D jobs share a fingerprint, the completely reconstructed table must match it. In 3D the integer number of blobs agrees exactly. Amplitudes, active centers, widths, densities and viscosity must agree within $10^{-14}$ relative, and device-computed peak normalization within $10^{-12}$. These limits follow the published A5 parity rule. Record original, regenerated and actually used fingerprints and maximum deviations. An accepted reference requires a positive finite normalization and finite nonnegative uncertainty.

The four primary sufficiency conclusions use the classified ST rows from all five or three meshes per dimension. One verified mesh failure falsifies that rule; all required meshes must pass to confirm. Otherwise label unresolved. Always present the independent secondary S result. The two-family tail test uses each qualifying family's top two rungs within 1 percent on both median and maximum; the selected family also needs a demonstrated tail. Invalid or failing rungs in a selected suffix count as failures on an anchor-qualified mesh. Eligible-case uncertainty entering these bounds comes from original metadata. All-case summaries include finite errors even when a ranking is ineligible. Report null, missing and invalid results as such.

The independent witness checker re-scores all five post-initial times for both S and ST for each stored witness, every bank and FOM field at cases 0 and 2 in 2D, and every bank coefficient at every case in 3D. On 3D there are no independent saved full-solver field witnesses. Reject mismatched reference bytes, a swapped physical case or a corrupted error table. For POD retain solver return reasons, per-step stationarity, damping, coefficients and fields on two named cases. Summarize all finite-field accuracy, per-case validity, fraction of nonstationary steps and all-step exits. New native POD runs do not repeat historical tightened-solve or whole-residual certificates; identify this limitation beside these descriptive baselines.

Timing uses six fixed cases, three main and five confirmation repetitions for the bank and full solvers on one GPU. The more expensive full-field and confirmation measurements exist for the preselected lattice and the dense anchor, not for every Gauss subject. Raw per-case repetitions are retained. The A2.4 timing checks require outputs to agree with the scored trajectory and enforce both within-block and main-vs-confirm agreement to 10 percent. A failed timing check is reported separately from accuracy. Report speeds only for comparisons in the same block and meeting the numerical, timing, and like-accuracy conditions. For the independently run native POD controls the measured query returns the entire field; the extra per-step certification is offline and timed outside the field query.
