The a-weights build the time derivative; the b-weights say where the right-hand side F is evaluated (new time b0, old time b1). Scheme sets accuracy: at r = 384, BE gives 0.98 % median / 3.0 % worst, CN-R 0.20 % / 1.8 %. It barely changes cost, because each step is still one small nonlinear solve of the same size (iterations per 50 steps: 51.5 to 54.3 for both schemes). CN-R's order is below 2 because of the two first-order start-up steps. GAL-CN (square Galerkin tests instead of least squares) reaches order 2.0 but is a diagnostic only.
