Every measured number below is formatted by a script from `runs/<attempt>/archive/output/audit.json` (the independent on-cluster NumPy audit); none is typed by hand. ## Ideas not run (budget of 8 GPU jobs spent)

- Sine-mode enrichment of the square bank to break the 0.742 % floor (would be a labelled, partly spectral arm).
- Pinned host buffers / asynchronous copies — would help every subject equally, like S6.
- A 1024² square anchor on the same H200, for a three-point same-GPU mesh series (the 1024² value is p-linear's, another job).
- f32-I/O twins of CG 0.2 / 0.3, to bracket the matched-accuracy CG under the f32 contract as well.
