# Curved two-dimensional reference control implementation

This is a review candidate, not executed numerical evidence. No NGSolve package has been installed, no allocation submitted, and no reference or training gate passed by this lane. The central `DESIGN.md` amendments supersede the earlier discovery thresholds.

`fom.py` implements curved triangular Taylor–Hood stationary solves with gradient-form diffusion and the matching natural outlet. The explicit alternative symmetric-traction configuration changes the weak diffusion too and is a separate problem. Fixed velocity and pressure scales normalize the assembled free-DOF residual. A Stokes solve initializes damped Newton; independent coefficient-form residual assembly certifies the returned state, and a finite-difference action check tests the Jacobian on a perturbed state. Direct linear residuals, every Newton iteration and damping, finite-element counts, estimated factorization memory, and peak process memory are saved. Every case has a fresh output directory and refuses overwrite.

Three smoke configurations are frozen. The empty channel checks exact Poiseuille velocity/pressure and positive shear force on the stationary walls. The manufactured case uses the **actual curved obstacle geometry**, exact nonzero velocity on every essential boundary, nonzero advection, nonconstant pressure, consistent body force, and nonzero natural outlet traction. Independent SymPy derivatives and exact analytic closed-circle forces are saved in `manufactured_witness.json`. The DFG anchor has no body forcing, no slip on walls/obstacle, and the published inlet/outlet. Its coarse smoke is not accepted reference data even if individual force values look plausible.

Metrics serialize numerators and denominators. Pressure error uses unshifted characteristic-scaled RMS, with reference-relative pressure explicitly secondary. Divergence uses the central fixed characteristic normalization. Total boundary flux is separate from inlet/outlet mass; the latter is not a local divergence certificate and is not an appropriate manufactured-case conservation gate when that manufactured case has nonzero wall flux. A2 gradient-form momentum/energy balances retain finite-divergence terms and source contributions. Physical symmetric-stress balances are separately recorded. Their denominators sum absolute individual contributions, with top and bottom wall labels kept separate. Both surface stress definitions and variational reaction forces use outward-fluid-normal sign `minus`; a direct exact wall-shear control pins the sign before the anchor.

The solver exports its curved mesh, FE solution, full positive mapped volume rule, boundary rule, velocity/pressure and component-by-coordinate gradients. Element Jacobian determinants and weights must be positive. Pressure probes evaluate the FE field at exact coordinates. Geometry error and boundary trace are sampled on the actual FE geometry; exact-geometry neural compatibility remains a later ROM gate. `seed` records the campaign's mesh provenance, but Netgen does not expose a seed option here: deterministic meshing is used, and a mesh file/hash—not a claimed random seed effect—is the reproducibility object.

`dependencies.py` downloads only the wheel URLs whose hashes are pinned in `DEPENDENCIES.json`. Its explicit install mode requires the designated cluster interpreter and a new target within this lane's namespace. `--no-deps --no-index` prevents any shared-environment dependency resolution. NGSolve runs on CPU; the batch still requires the repository's JAX GPU preflight and counts its full GPU reservation. `cluster/smoke.sh` stays within twenty minutes, sixteen CPUs, and 64 GiB. All caches/output reside under the job directory in paralab. No job is submitted by these scripts.
