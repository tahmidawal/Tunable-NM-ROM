# Guarded small-system kernel pilot

The user asked to keep the approved worktrees separate and keep pushing. This
bounded follow-up changes the small damped-normal linear solve only; frozen
checkpoint, Gaussian family and development cohort are retained. Configuration
and numerical agreement limits are frozen in `config03.json` before submission.

The specialized kernel applies symmetric diagonal scaling followed by unrolled
Gauss–Jordan elimination to the SPD system from the original LM algorithm:

$$A=J^T J+\lambda\left(\operatorname{diag}(\operatorname{diag}(J^T J))+
10^{-30}I\right),\qquad A\Delta z=-J^Tr.$$

The original `ctol_tol.lm_tau_poisson` source is unchanged and remains a complete
modular/fused query control. The unrolled elimination is the existing project
algebra, now with diagonal scaling and a backward-error guard. Nonpositive
diagonal, nonfinite output or an excessive normalized linear residual triggers
the generic solver. Guard calculations and fallback are inside the timed query;
every specialized invocation retains maximum linear residual and fallback count.

The linear backward error uses a scale-aware denominator:

$$\eta=\frac{\|A\Delta z-b\|_2}{\|A\|_F\|\Delta z\|_2+\|b\|_2}.$$

The same objective, mean-training-code initialization, trust radius, damping,
acceptance and stopping rules are used. Different floating-point linear algebra
may change later trajectories and counters; no bitwise identity is presumed.
Predeclared field, latent and initial-residual-scaled objective agreement limits
are enforced in addition to physical accuracy and solver-validity checks.
Nonstationary tighter solves remain invalid even when the residual is small.

Synthetic controls include a condition-number ladder with known solutions and
an out-of-contract non-SPD fallback case. Untimed deterministic actual-checkpoint
trajectory replays archive every normal matrix, right-hand side, step, damping,
acceptance and latent iterate. Independent CPU condition/eigenvalue/residual
checks audit those systems. Replay agreement with query outputs is explicit;
replay timings are never used as complete-query costs.

The paired pilot compares original modular, original fused and specialized
fused queries plus efficient same-grid and coarse-grid DST. Every repetition
returns a full host field from a full host source, with errors scored from that
same invocation. References are regenerated by nested independent SciPy FD-DST
solves. Reference differences remain empirical; no rigorous continuum bound is
claimed. Latency uses case medians before the cohort median, and cost ratios use
ratios of case medians before the cohort median.

## Plain-language glossary

- **SPD / normal system:** symmetric positive definite / small equations formed
  from the residual Jacobian to propose a nonlinear solve step.
- **Gauss–Jordan / diagonal scaling:** elimination of matrix columns / rescaling
  variables to reduce column-magnitude differences without changing the equation.
- **Backward error / condition number:** normalized residual of the linear solve /
  sensitivity of the solution to numerical perturbations.
- **Fallback / guard:** using the original generic solver / checks deciding when
  the specialized result is numerically acceptable.
- **LM / trust / damping:** Levenberg–Marquardt nonlinear optimization / allowed
  step size / regularization controlling a proposed step.
- **Parity / replay / counter:** numerical agreement / separately repeated
  diagnostic solve / recorded work or stopping statistic.
- **Fused / modular / DST:** one compiled pipeline / separated stages / direct
  discrete sine-transform full solver.
