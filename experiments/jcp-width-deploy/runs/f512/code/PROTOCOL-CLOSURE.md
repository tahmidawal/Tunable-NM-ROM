## Bounded sparse bridge on development data only

The selected $R'=512,M=8192$ model uses 65025 interior sites. Fit two fixed on-grid supports: checkerboard $(i+j)\bmod2=0$, and the complement of even-even sites. Node indices are one-based interior coordinates. The respective sizes are approximately $4M$ and $6M$. Neither is random nor an off-grid strong-form scheme. Nonlinear advection uses exactly the original sign-upwind neighbors. Cached linear weak terms remain exact.

Fit nonnegative quadrature weights to **decoder-output snapshots**, never residual snapshots: accepted development cases 0,1,2 at time indices 0,10,20,30,40,50 from the qualified R512/M8192 trajectories. Each snapshot is divided by its physical mass norm. Fit its first 8192 unscaled sine moments with one common positive-weight rule. Dimensionless weights multiply dense mass $1/N^2$. Start with uniform total-mass weights on each support. Use a matrix-free bounded least-squares solve (`L-BFGS-B`, lower bound zero, at most500iterations, ftol1e-14,gtol1e-10,maxls30). This is approximate NNLS; retain termination and projected-gradient norm, and do not label it an exact optimizer if it does not satisfy its gate. No enormous explicit snapshot-by-test-by-node matrix is formed.

Separate fit coverage and evaluation: evaluate all reached states of development cases3,4,5 and unused time indices from cases0,1,2. Save absolute and reference-scaled moment errors. Evaluate residuals and common physically normalized Jacobian directions at time indices1,10,25,50 of cases3,4,5. Directions are generated with fixed seeds1701,1702,1703 in mass-orthonormal coefficient coordinates. Residual discrepancy is normalized by each case's initial mass norm; action discrepancy uses the dense action norm and also retains its absolute value. Compare a sampled weighted-QR native initial fit with the dense native fit on these same held-out development cases, including rank/conditioning and physical field discrepancy. Fresh confirmation data are never fit or evaluated for rule selection.

A rule is eligible to continue only if (a) all weights finite/nonnegative, normalized projected-gradient infinity norm at most1e-8; (b) worst held-out normalized snapshot-moment error at most1e-2; (c) residual discrepancy at most1e-5 initial mass units, all action relative discrepancies at most1e-3; (d) sampled cold-start rank512 and worst dense/sampled initial field difference at most1e-4 initial norm; and (e) unique physical evaluation sites including **all possible upwind neighbors** at most80% of dense interior sites. If and only if at least one rule passes all gates, run its dense/sparse PDE comparison on held-out development cases3,4,5 with both existing solver tolerances, then the fixed $\Delta t\in\{0.005,0.0025\}$ interaction. Require full stationarity, retained reference checks and maximum dense/sparse field discrepancy at most $\min(10^{-4},0.05e_{dense})$. Only then is a separate complete-query cost measurement meaningful. Otherwise no sparse deployment/speed claim is admitted, and no fresh-case rule experiment is needed.
