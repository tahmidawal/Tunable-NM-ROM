# One coarse native producer and binary reload control

This unexecuted candidate tests the G2 producer interface on newly generated coarse DFG geometry. It grants no physical reference, training or ladder admission. The executed smoke07 controls remain immutable.

The source adds the previously prepared producer checks to the accepted A8 FOM: ordered FE layout, non-symmetric affine gradient, prescribed-FE essential trace, positive full quadrature with an exact-solid inclusion audit, saved Jacobians, and complete source/output provenance. Physical geometry, spaces, nonlinear/linear tolerances, quadrature and resource guards are byte-equivalent in configuration to smoke07. The final A8 helper and preflight are byte-identical. `SOURCE-CANDIDATE.json` enumerates every runtime input and the complete configuration delta. `DELTA-AGAINST-A8.patch` isolates the FOM additions; `reference_export.py` is the separate producer helper to review.

The bounded script runs dependency/API preflight and one coarse DFG producer under the existing one GPU, sixteen CPU, sixty-four GiB, twenty-minute allocation. Common-lift export is disabled in this control. The producer launches a fresh Python interpreter to reload its exact new binary mesh and saved solution/Stokes files. The original native mesh and FE objects cannot pass across this interpreter boundary. Original curve order, config, layout and mesh hashes are serialized before the child starts. Both PIDs, command, return code, stdout, stderr, child peak RSS and per-array errors remain evidence. A child failure fails the producer; no fallback, regeneration, re-curving or retry occurs.

`PROVISION.json` is staged as root `REPAIR.json`, binding the unchanged pinned-wheel prefix installer to the exact fresh `g2-native01` directory. Historical repair descriptors remain unchanged. This file is provision metadata for the new control, not an automatic retry authorization.

The format contract is explicit: filename `mesh.vol.bin`, format `netgen-binary-archive-v6.2.2608`, and policy `saved_curved_binary_verified_fresh_process_no_recurve`. These appear in mesh identity, reload certificate and export manifest. Old text meshes and old reload identities do not satisfy this contract. The ROM owner is separately preparing the adapter binding; no admission bypass is introduced here.

Pinned Netgen source in `source-evidence/` confirms the binary extension routes to `BinaryOutArchive` and `BinaryInArchive`, with raw-double serialization of curved coefficients. This is API support, not round-trip evidence. Converting a previous text mesh cannot recover its rounded coefficients. The candidate therefore generates a new mesh and compares saved in-memory samples against fresh-process evaluation at the existing $10^{-10}$ relative-max tolerance. Every saved physical point, Jacobian, positive weight, velocity, gradient, pressure, boundary label, raw/oriented normal and solution/Stokes coefficient is compared. Ordered FE layout and actual returned normal coefficients have independent checks. Native precision remains unmeasured until the released control runs.

The quarter-size draft fails existing point, single-array and moment-matrix caps; no cap is changed. ## Glossary

G1: initial solver and geometry controls. G2: physical reference qualification. FE: finite element. A8: the accepted fluid-outward normal repair. Binary archive: an exact-byte serialization candidate for the mesh. Fresh process: a new Python interpreter that reconstructs native objects from saved files. RSS: peak resident memory reported by the process. Full rule: every positive mapped reference quadrature point. NNLS: nonnegative least squares for fitting positive quadrature weights. Planning envelope: a conservative resource estimate, not a measured bound. Admission: the independent decision that all required physical gates pass.
