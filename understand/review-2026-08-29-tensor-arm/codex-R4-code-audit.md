# Independent code audit

## Findings

- **Major — the large-\(N\) exponents are not controlled scaling measurements.** The \(N=16384\) and \(65536\) points came from different jobs, nodes, commits, and independently trained decoders ([TENSOR-NOTES.md](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/TENSOR-NOTES.md:409), [TENSOR-NOTES.md](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/TENSOR-NOTES.md:469)). `gen_ladder.py` fits a slope to those two cross-job observations ([gen_ladder.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/runs/b1dtensor/gen_ladder.py:163)). Thus tensor \(-0.019\) and oracle \(+0.31\) are two-point descriptive ratios, not defensible cost exponents. The notes partly admit this as “indicative,” but present the numbers prominently as an answer ([TENSOR-NOTES.md](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/TENSOR-NOTES.md:350)). A same-process, same-GPU \(16384/65536\) timing run is required.

- **Major — tensor and oracle do not share everything except advection in the optimized timing path.** Their reference residuals do: oracle computes full-grid `upwind(G@h)` while tensor substitutes \(Q\)'s quadratic contraction ([b1d_fast_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_fast_common.py:143), [b1d_fast_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_fast_common.py:157)). But the production tensor arm also receives a tensor-specific lean head/residual fold ([b1d_fast_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_fast_common.py:398), [b1d_fast_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_fast_common.py:470)), whereas the oracle falls through the non-lean path ([b1d_fast_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_fast_common.py:575)). The driver explicitly disables this fold only for `tensor_nolean` ([sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:470)). Accuracy remains clean; optimized tensor/oracle timing must use `tensor_nolean`, or be labelled as algorithm-plus-optimization. Tensor/NNLS parity is less affected because sampled arms have an analogous fold.

- **Minor — timing arms were not interleaved as reported.** The four-mesh driver runs all trajectories and repetitions for one arm before advancing to the next ([sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:464)), contradicting the report’s “arms interleaved” statement ([report](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/reports/2026-08-29-b1d-tensor-sample-free-burgers.md:128)). JOB A alternates \(N\), but retains fixed `oracle,base_tight,tensor` arm order ([sep_b1d_ladder.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_ladder.py:129)). This weakens percent-level timing ratios, though the broad “parity” classification survives.

- **Minor — “e2e” is steady-state online cost, not first-use cost.** \(Q\)'s \(O(N)\) build is outside the timed region ([sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:318)); timed e2e contains IC fit, rollout, and decode only ([sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:493)). This is consistent with excluding the NNLS offline fit, but must remain explicitly “online amortized”; at \(N=65536\), the recorded tensor build is about 304 ms.

- **Minor — “every LM candidate” is too broad.** The audit probes only after finite, trust-radius, and tiny-step rejection checks ([b1d_tensor_audit.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_tensor_audit.py:263)). It covers every residual-evaluated in-radius candidate, accepted or rejected, but not every proposed LM step.

- **Nit — tensor artifacts falsely record \(m=n_i\).** Since both oracle and tensor use `X_v=None`, shared metadata assigns the tensor full-grid sample count ([sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:481)). This does not affect execution but contradicts the zero-sample interpretation in machine-readable results.

## Checks that survived

\(T\) is constructed solely from \(\Phi,G,\Delta x\), with no truth, test trajectory, or oracle output input ([b1d_tensor_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_tensor_common.py:36)). The oracle really uses the sign-upwind full-grid stencil ([b1d_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_common.py:123)) and matches the committed baseline residual ([sep_b1d_scale.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_scale.py:268)). Test truth is regenerated by the tridiagonal FOM under test seed 1, versus training seed 0 ([b1d_common.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/b1d_common.py:288), [sep_b1d_scale.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_scale.py:52)). Errors are independently calculated for each arm against that FOM truth ([sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:519)); no oracle-output caching path exists.

TB, TA, T0, and TQ implement their stated limited checks: accumulation order, backward-stencil algebra, positive-state oracle equality, and a recorded 32-state residual/Jacobian comparison ([sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:318), [sep_b1d_tensor.py](/home/tahmid/Dev/pod-ae-nmrom/Tunable-NM-ROM-Claude/worktrees/2026-08-29-b1d-tensor/experiments/separable-decoder/sep_b1d_tensor.py:369)). The \(1.2\times10^{-6}\) rollout-error agreement is therefore not explained by truth/test leakage or reused oracle outputs.

**Verdict: legitimate with corrections (large-\(N\) exponents only indicative; scope “same path” to the reference residual; use `tensor_nolean` for oracle timing; call timings steady-state online; narrow the candidate-audit wording).**
