# Heterogeneous nonlinear Heat with AmgX

This experiment tests a pure nonlinear coordinate-manifold ROM against a tuned
Newton–FGMRES–AmgX FOM on an L-shaped heterogeneous nonlinear Heat benchmark.

The benchmark, finite search budget, gates, and untouched confirmation protocol were locked
before implementation in [PREREGISTRATION.md](PREREGISTRATION.md). Numerical results will be
generated from machine-readable run artifacts; this file will remain a short entry point rather
than a hand-maintained result table.
