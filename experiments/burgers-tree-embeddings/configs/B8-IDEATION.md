The B7 parent's failure does not establish that a nonlinear residual tree fails. Test newly learned shared local features with a lower-dimensional nonlinear child coefficient manifold, freezing the stable parent weights while jointly fitting parent and child codes. The factorized construction enables caching spatial features during embedding fits and PDE steps; a directly modulated network at every quadrature point would make these fits substantially more expensive.

The first 16 coefficients are the scaled code itself; the remaining 48 are a zero-subtracted nonlinear tanh head. Newly added zero child codes exactly preserve the existing field. All child networks share weights. The feature bank is trained anew against the B7 residual, not copied from B6's failed fixed feature span. A direct full-feature coefficient fit is a capacity diagnostic/control, not the nonlinear model or a replacement for it.

At 20 nodes and 64 features, a float64 256-square feature matrix occupies approximately 671 MB; keeping one per selected trajectory can waste many gigabytes, especially for identical uniform trees. Tree structure alone is insufficient. Comparisons with CROM and SNF-ROM must use strong matched-data trained models and preserve reproduction limitations.
