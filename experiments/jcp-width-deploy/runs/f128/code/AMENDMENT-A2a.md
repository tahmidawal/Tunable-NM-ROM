# Portable cohort identity check after an early metadata failure

Attempt p04 stopped before any reference or reduced solve because its regenerated parameter bytes differed from the local metadata hash. The retained `checks/parameter-portability.json` contains both arrays and every entry's distance in representable floating-point values. The mismatch occurs only in one viscosity's last bit; seeds, group counts, centers, widths and amplitudes are unchanged. This is a metadata portability failure, not scientific evidence.

The retry preserves the original cases, seeds, group counts and NumPy random generator. It independently extracts the original `params_draw` and `cohort` functions from byte-identical archived source files and regenerates the original `dev6` recipe on the **same host** as the new recipe. The full arrays must agree bit for bit; their exact host-specific hashes are recorded. No imported module or other cohort is executed through this source extraction.

As a separate portability witness, all first four parameter columns must match the original local descriptors bit for bit, and viscosity differences must be no greater than four units in the last place. The local reference descriptors themselves retain their original byte hash. These descriptors are validation metadata only: the solver always uses the original recipe regenerated on the cluster, never values copied from the local machine. This narrow cross-platform check does not replace the same-host exact identity requirement.

Move the guard ahead of bank construction and write the full attempted descriptors and check results atomically before asserting success, so even an early failure retains its evidence. A metadata-only same-host preflight will run before the retry is submitted; the actual compute process repeats the guard. No physics, solver tolerance, reference qualification or primary outcome changes. Attempt p04b retains the four remaining development cases, all registered test counts, one GPU and the existing 45-minute ceiling. The failed p04 remains in the budget and archive.

Glossary: a unit in the last place is the spacing between adjacent representable floating-point numbers; bitwise agreement means the stored bytes match exactly; a host is the machine executing the generator; validation metadata identifies an input but does not replace the regenerated input.
