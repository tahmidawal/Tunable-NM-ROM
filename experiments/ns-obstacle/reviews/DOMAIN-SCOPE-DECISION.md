# Concrete scope decision after the inlet-sensitivity failure

The original fixed DFG channel remains a legitimate finite-domain benchmark. Its upstream-extension sensitivity fails the frozen gate and must remain failed. The current design explicitly requires all G2 gates before training, so a finite-domain-only continuation cannot be called a pass of the original G2 protocol.

## Option A: explicitly revise the task to a finite-channel ROM

Keep the original DFG geometry and parameter population. Complete every numerical, force, pressure, spatial/order, noise/uncertainty, data, ROM and fair-timing check. Preserve the domain-sensitivity failure and complete its diagnostics, but make no length-independent or isolated-flow claim. Record the user-authorized scope change as a protocol deviation/amendment and use a distinct finite-domain admission record; never set the failed domain gate to passed. Then train/test the actual bank and POD on this fixed finite problem. This retains the existing geometry and most evidence, but requires an explicit user scope decision because it changes the original all-G2 training condition.

## Option B: retain the original domain-adequacy requirement

Freeze exactly one new, project-defined longer-channel candidate and one further inlet test before any new solve, preserving every numerical threshold and a stop-on-failure rule. A conservative candidate proposed by Claude is inlet at−0.6 with one test at−0.8; these are proposals, not released settings or measured adequacy. Do not use the consultant's heuristic decay estimate as evidence that the gate will pass. Canonical DFG stays a separate code/literature control. The new geometry needs its own h/p/noise, outlet sensitivity, immutable lift, ROM geometry contract and full parameter qualification, within a separately verified remaining compute/memory/disk budget. Do not promote the test geometry after failure or search repeatedly.

Independent Codex review considers either an explicitly authorized finite-domain task or a separately frozen longer-channel family scientifically coherent. Claude rejects treating Option A as a mere clarification of existing G2: it is a protocol deviation, not original-protocol admission. Both agree that silent waiver, relabeling an extended channel as DFG, or training on a claimed passing domain gate is unacceptable.

While the choice is pending, only independent useful work continues: finish domain diagnostic comparisons, validate efficient readout/common-rule evaluation, retain evidence and review memory-safe ROM preparation. No training/population admission or new geometry solve is released by this note. The existing compute cap remains unchanged.
